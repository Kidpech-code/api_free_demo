⚙️ How It Works
3 ขั้นตอนสู่ Orbit
ออกแบบมาให้ง่ายที่สุด ตั้งแต่ขอ Token ไปจนถึงการทดสอบ API แบบ Full-Stack
STEP 01
🔑
ขอ Token ของคุณ
กรอก user_id ที่ต้องการ ระบบจะสร้าง JWT Token ที่ผูกกับ namespace ของคุณใน Redis มีอายุ 3 วัน และ expire อัตโนมัติ ไม่ต้องจัดการ lifecycle เอง
›
STEP 02
📖
ศึกษา API Docs
อ่าน Endpoint ทั้งหมด พร้อมตัวอย่าง Request/Response ครบถ้วน ทั้งการ Create, List ด้วย Cursor Pagination, Bulk Insert และ Rate Limit Headers
›
STEP 03
⚡
ทดสอบใน Playground
ใช้ In-Browser Playground ที่เปรียบเสมือน Postman ส่ง Request จริงไปยัง API ดู Response, Headers, และ Metrics แบบ Real-time ได้ทันที
🔑 Token Generation
ขอ Access Token
Token ผูกกับ user_id ของคุณ — ข้อมูลทุกอย่างถูก shard ตาม user_id อัตโนมัติ User A จะไม่เห็นข้อมูลของ User B
🛰️
สร้าง Sandbox Token
Token ถูก sign ด้วย HS256 · มีอายุ 72 ชั่วโมง · เก็บ metadata ใน Redis
⚠️ ไม่สามารถเชื่อมต่อ API ได้ — ตรวจสอบว่า Server กำลัง run อยู่ที่ localhost:8080

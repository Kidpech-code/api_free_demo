Quick Start

Start in 30 Seconds

No setup needed — copy, paste, run.

Health Check

Verify the API is online — expect {"status":"ok"}

curl https://freeapi.kidpech.app/api/v1/health

Register

Create an account — you'll receive an access token immediately.

curl -X POST https://freeapi.kidpech.app/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"you@example.com","password":"MySecret123","name":"Your Name"}'

Login & Get Tokens

Authenticate — receive access_token and refresh_token.

curl -X POST https://freeapi.kidpech.app/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"you@example.com","password":"MySecret123"}'

Create a Profile

Use your token to call a protected endpoint.

curl -X POST https://freeapi.kidpech.app/api/v1/profiles \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"first_name":"Demo","last_name":"User","bio":"Learning APIs"}'

Engineering Patterns

Production Patterns You Can Learn From

Real-world engineering patterns implemented in this API — the same concepts powering systems at scale.

🔄
Graceful Degradation
Resilience Pattern
The app starts even when the database is unavailable. Health check always responds 200, while DB-dependent endpoints return 503 until the connection is established.
// Service layer checks repository availability if s.repo == nil { return nil, ErrDatabaseUnavailable } // Handler maps to HTTP 503 Service Unavailable
🔁
Retry with Exponential Backoff
Reliability Pattern
Database connections retry up to 5 times with exponentially increasing delays. Prevents thundering herd on startup and gives dependent services time to become ready.
for i := 0; i < 5; i++ { if err := db.Ping(); err == nil { break } time.Sleep(time.Duration(i+1) * 2 * time.Second) }
⛓️
Middleware Chain
Cross-cutting Concerns
Every request flows through a composable middleware pipeline. Each middleware is a single-responsibility function that can be tested independently.
router.Use( middleware.RequestID(), middleware.CORS(cfg), middleware.Logging(logger), middleware.RateLimit(limiter), )
🗃️
Repository Pattern
Data Access Abstraction
Domain layer defines repository interfaces. Infrastructure provides concrete implementations. Swap PostgreSQL for MySQL without touching service code.
// Domain defines the contract type Repository interface { Create(ctx, profile) error FindByID(ctx, id) (*Profile, error) } // Infrastructure implements it type pgRepo struct { db *sqlx.DB }
📊
Structured Observability
Three Pillars
Complete observability stack: Logs via structured Zap logger, Metrics via Prometheus (latency histograms, counters), Errors via Sentry with context enrichment.
// Every request is traceable logger.Info("request completed", zap.String("request_id", reqID), zap.Int("status", 200), zap.Duration("latency", elapsed), )
💉
Dependency Injection
Testability Pattern
All dependencies are injected through constructors. Services receive repository interfaces, handlers receive services. Unit testing with mocks requires no database.
// main.go wires everything repo := db.NewUserRepo(database) svc := user.NewService(repo, jwtMgr) hdl := user.NewHandler(svc) // Test with mock repo — no DB needed

package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

const base = "https://freeapi.kidpech.app/api/v1"

func main() {
    // Login
    body, _ := json.Marshal(map[string]string{
        "email":    "test@example.com",
        "password": "MySecret123",
    })
    resp, _ := http.Post(base+"/auth/login",
        "application/json", bytes.NewBuffer(body))
    
    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    tokens := result["tokens"].(map[string]interface{})
    token := tokens["access_token"].(string)

    // Get Me
    req, _ := http.NewRequest("GET", base+"/users/me", nil)
    req.Header.Set("Authorization", "Bearer "+token)
    resp, _ = http.DefaultClient.Do(req)
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Println(result)
}
